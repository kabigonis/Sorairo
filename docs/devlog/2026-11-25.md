# Sorairo Development Log - November 25, 2026

## Action tray rework

- Fixed icons freezing half-faded: the 2 s status tick cancelled in-flight tray animations. Refresh now only animates when an icon's target state changes.
- Tray can be opened by touch: added a chevron expander (the old reveal zone was an invisible area nobody could find). Empty tray space no longer swallows touches.
- Icons redrawn as solid Material Design Icons-style glyphs (what Omarchy's Nerd Font draws), 15 dp, with proper active colours. Added alarm and crescent glyphs; the bell slash cuts through the bell.
- Screen recording is real now (MediaProjection foreground service, saves to Movies/Sorairo).
- Reminders: the notification channel was silent (no sound, no vibration); replaced with an audible channel. The icon shows a pending reminder and can clear it. Falls back to an approximate alarm when exact alarms are refused instead of dead-ending in settings.
- Stay Awake no longer dead-ends without permission: it keeps the launcher screen on, and goes system-wide when "Modify system settings" is allowed. It switches itself off if the timeout is changed elsewhere.
- Tray state (Stay Awake, Night Light, DND, recording, reminder, sudo) is read from the real system state on every refresh.

## sudo

- The red glyph is now a privilege layer: Night Light, Battery Saver, Private DNS and system-wide Stay Awake ask for the device screen lock, unlocked for 5 minutes. Optional passwordless mode. Terminal commands: `sudo`, `night`, `awake`, `dnd`, `rec`, `remind`.
