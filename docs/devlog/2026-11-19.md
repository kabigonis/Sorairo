**Correction:** `8d7ea90` was the fifth commit and specifically the demo-replacement fix. It was not the initial PR commit.

### Implementation

Added `IslandView.kt` and integrated it into `MainActivity.kt`.

Features:

- Fixed transparent host overlay at the top centre.
- Collapsed clock pill and expanded activity view.
- Tap to expand/collapse.
- Long press to open Settings.
- 220 ms pill animation.
- PEEK scheduling through `nextWakeAt`.
- Pending callback cancellation on pause.
- Theme-aware text and styling.
- Dynamic Island Settings toggle.
- Terminal commands:
  - `island on`
  - `island off`
  - `island demo hud`
  - `island demo media`
  - `island demo timer`
  - `island demo alarm`
  - `island demo power`

### Demo replacement fix

Tablet testing exposed stale demo activities masking newer previews. The fifth PR commit clears previous `demo:` activities before submitting a new demo.

### Visual fixes

The sixth PR commit addressed two tablet-observed visual problems:

- Expanded island background was see-through.
- Progress bar could overflow the pill.

Changes in `IslandView.kt`:

- Forced the pill fill to full opacity while preserving the border.
- Enabled clipping on the pill and expanded content.
- Recalculated progress width during pill animation using the current animated width.

### PR scope

Verified changed-file list:

- `app/src/main/java/com/kabigonis/sorairo/MainActivity.kt`
