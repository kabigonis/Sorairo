# Sorairo Development Log — November 21–23, 2026

## Overview

This three-day period focused on finishing the status-bar and popup experience, adding battery and calendar surfaces, improving network/audio/display controls, and consolidating the Omarchy-inspired action tray. The work was merged into `main` through PR #77 on November 23.

## November 21

- Connected the active Android media session to the Dynamic Island implementation.
- Continued the staged Dynamic Island work, including its view and media integration.
- Merged the media integration work through PR #70.

## November 22

- Refactored the oversized `MainActivity.kt` into focused Kotlin files without intending to change runtime behaviour.
- Added and tested calendar date/grid calculations, then connected the calendar popup to the normal top-bar clock.
- Added an Omarchy-style calendar popup with month navigation and animation.
- Added the battery panel and improved its readout smoothing and visual animation.
- Removed the old Quick Settings surface in favour of focused top-bar panels.
- Added top-anchored popup positioning and custom status icons.
- Added the top-bar Wi-Fi, audio, and display panels.
- Improved DNS controls and the custom DNS dialog.
- Merged the calendar, refactor, and battery-panel work through PRs #71, #72, and #73.

## November 23

### Top bar and panels
- Fixed top-bar panel switching and segmented-slider behaviour.
- Refined icon order, clock underline/active state, calendar month animation, and DNS readback.
- Improved popup handoff between top-bar controls.

### Omarchy action tray
- Rebuilt the compact action tray with custom-drawn glyphs, touch-first targets, labels/tooltips, and active states.
- Added tray actions for screen recording guidance, reminders, night/day light, notification silence, Stay Awake, and the Android-incompatible sudo placeholder.
- Kept Android-specific limitations explicit where the platform does not expose an equivalent public action.
- Updated Stay Awake to use the system screen-off timeout when the user grants Modify system settings permission, with an attempt to restore the previous timeout when disabled. Device/OEM timeout limits still apply.
- Removed the Reminder notifications permission row from the permissions screen.
- Removed the Dynamic Island settings toggle and disabled its runtime UI for this build, restoring the normal clock display. The underlying Dynamic Island source files remain in the repository but are not active in the launcher UI.

### Popup dismissal
- Added active-popup tracking for Wi-Fi, Audio, Display, Battery, and Calendar.
- Added same-control toggle routing and direct handoff when a different top-bar icon is tapped.
- Changed outside-touch handling so the activity can process the first tap instead of Android dismissing the popup before the app can route it.
- The final single-tap dismissal behaviour still needs on-device confirmation; earlier tablet recordings showed that popup dismissal was not consistently single-tap.

### Build and merge
- Fixed a Kotlin compilation error in `TopBar.kt` caused by checking the backing field of the `clock` lateinit property from an extension function.
- GitHub Actions build for final PR head `4e4e8db` completed successfully.
- Squash-merged PR #77 into `main`.
- Merge commit: `9164e472a36d643c528f0487835a012e62ac60df`.

## Validation notes

- The final PR head passed the GitHub Actions `build` check.
- A successful CI build confirms compilation and the configured automated checks; it does not confirm tablet UI behaviour.
- Stay Awake behaviour, popup single-tap dismissal, panel switching, and layout/interaction details still require testing on the Lenovo TB351FU running Android 16.
